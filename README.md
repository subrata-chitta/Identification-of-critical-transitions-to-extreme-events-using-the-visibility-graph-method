# Identification of critical transitions to extreme events using the visibility graph method

This repository contains the Python codes used to reproduce the numerical results and figures presented in the manuscript:

**"Identification of Critical Transitions to Extreme Events Using the Visibility Graph Method"**

## Files

- `GV_lin.py` – Python code used for the visibility-graph analysis.
- `lin_bif.py` – Python code used for the bifurcation and numerical analysis.

## Requirements

The codes are written in Python and require standard scientific-computing packages such as NumPy, SciPy, Matplotlib, and NetworkX.

## Usage

Run the Python files using:

```bash
python GV_lin.py
python lin_bif.py
